# 📈 Telegram-бот для моніторингу акцій під Interactive Brokers (IBKR)

Розумний бот для відстеження спадів якісних світових гігантів (S&P 500, NASDAQ, європейські лідери типу ASML, SAP) та надсилання сигналів на покупку в Telegram.

---

## 💡 Як працює стратегія (Buy the Dip on Quality)

Бот відфільтровує ринковий шум і шукає вигідні точки входу за 3 критеріями:
1. **Якість бізнесу (Blue Chips & Titans):** акції з високим консенсусом аналітиків Волл-стріт (*Buy / Strong Buy*) та потенціалом росту до цільової ціни від **+10%** до **+60%**.
2. **Фактор падіння (Технічний дип):**
   * Падіння від 30-денного піку на **≥ 7-10%**
   * АБО денний спад на **≥ 3-4%**
   * АБО індикатор **RSI(14) ≤ 40** (перепроданість, висока ймовірність відскоку).
3. **Захист від спаму:** бот надсилає сповіщення не частіше 1 разу на 12 годин для однієї акції.

---

## 🚀 Швидкий запуск

### 1. Подвійний клік на файл:
Просто запустіть файл **`start_bot.bat`** у папці проекту!

Або через термінал:
```bash
cd stock-alert-bot
node index.js
```

### 2. Підключення в Telegram:
1. Перейдіть у Telegram до вашого бота: **[@ksdfskdfbot](https://t.me/ksdfskdfbot)**.
2. Натисніть кнопку **`/start`**.
3. Ваш профіль автоматично підключиться до розсилки сповіщень.

## 📱 Команди в боті

| Команда | Опис |
|---|---|
| `/signals` | Просканувати ринок зараз і показати акції в зоні покупки |
| `/watchlist` | Переглянути список відстеження та поточні ціни |
| `/check <TICKER>` | Повний аналіз будь-якої акції (наприклад: `/check NVDA` або `/check ASML`) |
| `/add <TICKER>` | Додати акцію до списку відстеження (наприклад: `/add INTC`) |
| `/del <TICKER>` | Видалити акцію зі списку |
| `/testalert` | Отримати зразок повідомлення-сигналу |
| `/help` | Довідка з інструкціями |

Також можна просто відправити боту символ акції (наприклад, `INTC` або `NVDA`), і він миттєво поверне детальний аналіз.

## 🏛 Як купувати в Interactive Brokers (IBKR)

1. Отримавши сигнал у Telegram, зверніть увагу на:
   * **Тікер:** наприклад, `NVDA`
   * **Біржу:** NASDAQ (для США) або Euronext/Xetra (для Європи)
   * **Поточну ціну та цільову ціну аналітиків**.
2. Відкрийте застосунок **IBKR Mobile** або **Trader Workstation (TWS)**.
3. Введіть тікер у пошук, виберіть акції (Stock) та виставте лімітний ордер (Limit Order) на покупку за поточною або бажаною ціною.

## ⚙️ Налаштування (.env)

У файлі `.env` можна змінити параметри:
* `SCAN_INTERVAL_MINUTES=30` — частота автоматичного сканування ринку (у хвилинах).
* `MIN_UPSIDE_PERCENT=10` — мінімальний очікуваний ріст за оцінкою аналітиків.
* `MAX_RSI=42` — поріг індикатора RSI.
